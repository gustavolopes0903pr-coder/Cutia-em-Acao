# Cutia-em-A-o
O Cutia em Ação é um projeto web informativo desenvolvido com HTML5 e CSS3. A proposta é apresentar de forma visual e intuitiva dados fascinantes sobre a cutia, como seu porte, capacidade de salto, hábitos diurnos e importância ecológica.  O projeto conta com um layout agradável utilizando imagem de fundo temática e efeitos interativos.
